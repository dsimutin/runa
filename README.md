# Telegram Rune Oracle Bot

Telegram-бот на Python: руна дня + вспомогательная руна, ответ одной руной и трёхрунный расклад.

## Возможности

- `/start` — приветствие, сохранение имени пользователя.
- `/runa` — две разные руны на календарный день:
  - основная руна — главный совет/энергия дня;
  - вспомогательная руна — дополнительная энергия или совет дня.
- `/ask <вопрос>` — ответ одной случайной руной:
  - 50% — короткое «нет» из `answer_no`;
  - 50% — развёрнутый совет из `answer_yes`.
- `/rasklad <вопрос>` — расклад из трёх разных рун:
  - ситуация → препятствие → совет.
- Переключение расклада:
  - `USE_GPT=false` — бесплатная сборка из шаблонов;
  - `USE_GPT=true` — генерация ответа через OpenAI API.
- SQLite-хранилище:
  - `rune_bot.db`;
  - таблица ежедневных рун;
  - таблица имён пользователей.

## Установка локально

1. Установите Python 3.9+.

2. Клонируйте репозиторий:

```bash
git clone https://github.com/dsimutin/runa.git
cd runa
```

3. Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Создайте `.env` из примера:

```bash
cp .env.example .env
```

6. Заполните `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
USE_GPT=false
OPENAI_API_KEY=
OPENAI_MODEL=gpt-3.5-turbo
DB_PATH=rune_bot.db
```

7. Запустите бота локально:

```bash
python bot.py
```

Если `WEBHOOK_URL` пустой, бот запускается через polling — это удобно для локального теста.

## OpenAI-режим для `/rasklad`

Чтобы включить AI-ответы:

```env
USE_GPT=true
OPENAI_API_KEY=ваш_openai_api_key
OPENAI_MODEL=gpt-3.5-turbo
```

Если `USE_GPT=true`, но ключ не указан, бот ответит:

```text
Функция расклада с AI временно недоступна, используйте /ask или /runa
```

По умолчанию используется модель `gpt-3.5-turbo`, как указано в ТЗ. При необходимости можно заменить её через `OPENAI_MODEL`.

## Деплой на Render.com через webhook

1. Загрузите проект на GitHub.

2. На Render создайте новый **Web Service**.

3. Подключите GitHub-репозиторий.

4. Укажите настройки:

**Build Command**

```bash
pip install -r requirements.txt
```

**Start Command**

```bash
python bot.py
```

5. Добавьте Environment Variables:

```text
BOT_TOKEN=ваш_токен_от_BotFather
USE_GPT=false
OPENAI_API_KEY=
OPENAI_MODEL=gpt-3.5-turbo
DB_PATH=rune_bot.db
WEBHOOK_URL=https://your-render-service-name.onrender.com
```

`PORT` Render обычно задаёт автоматически. В коде есть запасное значение `10000`.

6. После запуска бот сам установит webhook по адресу:

```text
https://your-render-service-name.onrender.com/<BOT_TOKEN>
```

## База данных

SQLite создаётся автоматически при первом запуске.

Таблицы:

```sql
daily_runes(user_id, date, main_rune, aux_rune)
users(user_id, preferred_name)
```

Файл базы `rune_bot.db` добавлен в `.gitignore`, чтобы не попадать в репозиторий.

## Примечания

- В `runes_data.py` заполнены реальные данные для 6 рун:
  - Феху
  - Уруз
  - Турисаз
  - Ансуз
  - Райдо
  - Кеназ
- Остальные 18 рун добавлены как `TBD`, чтобы структура Старшего Футарка была полной.
- Команда `/rasklad` без вопроса отвечает:

```text
Напиши вопрос после команды, например: /rasklad Как улучшить отношения?
```
