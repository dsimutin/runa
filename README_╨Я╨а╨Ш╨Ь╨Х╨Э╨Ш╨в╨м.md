# Как применить

## Вариант А — патчем (быстрее)
```
cd runa   # твой локальный клон репозитория
git apply runa_fixes.patch
git add -A
git commit -m "Живость + баг-фиксы: ротация текстов, orientation->вердикт, синхронизация рассылки, парный расклад, традиционные значения рун"
git push
```
Если `git apply` ругается на конфликты — используй вариант Б.
