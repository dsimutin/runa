## Что исправлено, по темам

### 1. Живость и структура ответов
- Ротация формулировки вердикта в «Вопрос» да/нет — вердикт всегда однозначен, меняется только фраза
- Живые открывашки/закрывашки для карты дня и вопроса (использован уже написанный, но неподключённый пул фраз)
- Синтез-фраза в конце расклада из 3 карт, живая ротация вступления

### 2. Логические баги
- Вердикт да/нет был независимой монеткой — теперь честно завязан на положение выпавшей руны (тот же баг также был в отдельном обработчике «А ты говоришь правду?» — исправлен)
- Рассылка в 9:00 использовала свою отдельную, устаревшую версию текста карты дня — синхронизирована с основной кнопкой через общую функцию
- Парный/отношенческий расклад показывал тексты «Прошлое:»/«Будущее:» под подписями «Ты»/«Партнёр» — написан отдельный набор из 75 текстов специально для этой фичи
- Команда /ask использовала старую независимую монетку в обход уже исправленной логики — переключена на единую реализацию

### 3. Пустая руна (Wyrd)
- У карты дня не было вообще никакого текста для пустой руны — пользователь получал пустое сообщение (~1/25 случаев). Написан текст, подключён в центральную функцию — фикс закрывает все точки входа разом (кнопка, рассылка, месяц в годовом раскладе)

### 4. Подключение «умного» движка расклада
- В репозитории лежал недоделанный, более продвинутый механизм расклада (тема вопроса + группировка рун + связный синтез), который никогда не работал: нерабочий sitecustomize.py, отсутствующая функция bot.choose_distinct_runes
- Функция добавлена, движок подключён явно в коде с безопасным откатом на простую версию при сбое
- По ходу нашлись и исправлены старые написания ключей рун (teiwaz/berkana/inguz → tiwaz/berkano/ingwaz) в трёх разных файлах, из-за которых 3 руны получали текст-заглушку «значение ещё не добавлено»
- Движок изначально полностью игнорировал положение руны (всегда прямое) — исправлено, теперь показывает стрелку ↑/↓ и использует реальные тексты для перевёрнутого положения

### 5. Тон и персонализация
- Новый движок расклада был написан на «вы», весь остальной бот — на «ты». Все ~150 текстов переписаны на «ты» (местоимения, повелительные и изъявительные глагольные формы, прошедшее время переписано без гендерных форм)
- Имя пользователя добавлено один раз, в шапку расклада — не на каждую строку

### 6. Мёртвый код
- Удалены: gender_voice.py, sitecustomize.py, product_daily_text, product_question_text, rune_title, старый bot.send_one_rune_answer

### 7. Новая фича
- Кнопка «ℹ️ О руне» — традиционное/этимологическое значение всех 25 рун (Старший Футарк), отдельным голосом от коучингового тона, по запросу, не в основном потоке

### 8. Содержательный аудит трактовок
- Проверена дифференциация по 6 сферам, мотивирующая структура ответов (100% дают не только вердикт, но и причину+совет), найдена и исправлена единственная общая фраза-заглушка из 864

### 9. Техдолг с данными
- sphere_answer_texts вынесен из gzip-блоба в обычный читаемый Python-словарь (sphere_answer_data.py) — раньше правка одной строки давала diff на 900+ строк из-за пересжатия
