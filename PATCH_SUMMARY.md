# Rune bot data-only patch

Что внутри:

- `bot.py` — заменяет логику бота:
  - карта дня берётся из `rune_day_texts`
  - Да / Нет берётся из сферных ответов
  - расклад из 3 рун строится как прошлое / настоящее / будущее
  - GPT/AI-генерация не используется для трактовок
  - пустая руна (`wyrd`) имеет только прямое положение

- `rune_text_data.py` — сжатые данные из пользовательских файлов:
  - `runes_data.json`
  - `rasklad.rtf`, преобразованный в JSON
  - `runes_spheres_all.txt`, преобразованный в структурированные ответы

- `rune_text_repository.py` — единый слой доступа к данным.

- `rasklad_engine.py` — новый движок расклада прошлое / настоящее / будущее.

- `runes_data.py` — ключи рун приведены к данным пользователя:
  - `tiwaz`
  - `berkano`
  - `ingwaz`
  - `wyrd` для пустой руны

- `database.py` — карта дня теперь хранит одну руну и положение:
  - `up` = прямое
  - `rev` = перевёрнутое
  - для `wyrd` всегда `up`

Как залить:

1. Открой репозиторий `dsimutin/runa`.
2. Замени файлы в корне репозитория файлами из этого архива.
3. Добавь новые файлы:
   - `rune_text_data.py`
   - `rune_text_repository.py`
4. Коммит:
   `Use uploaded rune texts as the only interpretation source`

Важно:
- Папка `data/` в архиве добавлена как читаемая копия данных, но бот работает через `rune_text_data.py`.
- Если хочешь, можно дополнительно залить папку `data/` в репозиторий для ручной проверки текстов.
